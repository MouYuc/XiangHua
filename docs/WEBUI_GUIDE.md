# WebUI 使用说明

本地图形界面，浏览器一站式完成：**建声音 → 写台词 → 合成 → 试听 → 下载**。
导航只有三个目的地：**工作台 / 声音库 / 记录**；设置在侧栏底部，后台任务在顶栏「任务」。

> **2026-10-25 重设计**：界面按「任务为中心」重做（设计定稿见 `design/C-studio.html`）。
> 旧的 合成/训练/采集/音色/历史/设置 六个平级页面合并为：工作台（原合成）、
> 声音库（建档 + 训练 + 音色转换）、记录（原历史）；设置降级为弹窗。
> 仍是本地单用户原型，不是 B2B API。

## 启动

```powershell
# Windows
$env:GPT_SOVITS_ROOT = 'D:\AIVoice\GPT-SoVITS'   # 换成你的 GPT-SoVITS 路径
python tools\webui.py
```

```bash
# Linux / macOS
export GPT_SOVITS_ROOT=/path/to/GPT-SoVITS
python tools/webui.py
```

浏览器打开 <http://127.0.0.1:7860>。也可以前后端分离开发：`cd frontend && npm run dev`
（5173 端口，`/api` 自动代理到 7860）。

## 工作台（首页）

一条主路：**选声音 → 写台词 → 出结果**。

- **台词**：一行一句；空行和 `#` 开头的行不会合成。支持显式语言标记
  `<zh>/<yue>/<en>/<ja>/<ko>`（混读一行会自动分段并加 120ms 语种停顿）。
  回车换行、行首退格合并上一行；`Ctrl+Enter` 全部生成；支持导入 TXT。
- **结果长在每行下面**：已完成（试听/下载/单句重生成）、生成中（实时进度）、
  排队中、合成失败（含原因，可重试）、时长偏短（黄色警告，疑似截断）。
- **右侧检查器**：声音卡（点击去声音库）、语言、广普程度（关/轻/中/浓，
  只影响读音不动音色，「目的/的确」等固定搭配始终受保护）、参数预设
  （**清晰优先 / 表现力优先**，专业参数收进「高级参数」，改动 650ms 防抖自动保存）。
- 引擎未就绪时生成按钮上方会给出预热状态，可一键重试预热。

## 声音库

所有可用于合成的声音。

- **声线卡**：建档向导写入的命名声音，带版本号（v1、v2…）。点「用于合成」
  会把该卡的快照（模型 + 参考音 + 默认参数）写回引擎配置并回工作台。
- **当前音色**：内置档案，跟随设置里的模型与参考音频。
- **新建声音**（三种来源）：
  1. **一段自然说话录音**：上传访谈/播客/语音备忘，系统自动切片 → 质检 → 转写，
     你只在质检确认与命名两步出现；质检未达标只提示不拦截，看报告自己决定。
     确认后存为一张声线卡（快照当时的模型与参考音）。
  2. **多人素材分离**：进入「声音工作坊」。
  3. 导入已训练模型：训练完成后在工作坊「完成」一步扫描启用。
- **声音工作坊**（五步引导流）：上传素材 → 选择说话人（自动分清谁在何时说话，
  可试听样本）→ 校对（低置信错字有建议，可跳过）→ 训练（特征提取 → s1 韵律 →
  s2 音色，loss 曲线与日志实时可见，可停止；跑训练时可关闭页面，任务中心跟进）→
  完成后扫描产物一键启用。
- **音色转换（kNN-VC）**：把任意已配音人声转成某个声线卡的声音，适合翻唱/歌词
  重新定音；topk 越大越贴目标音色、越小越保留源细节；转换完可释放显存。

## 记录

最近 200 条合成记录，按日期分组；可回听、下载。文件清理后记录保留并显示「文件缺失」。
「清空记录」需二次确认。

## 任务中心（顶栏）

聚合全部后台任务（合成 / 声音建档 / 音色转换 / 训练 / 素材分析）：进度、阶段、
排队原因一目了然；训练任务可在此取消。关闭页面不影响后台任务。

## 其他

- **⌘K / Ctrl+K 命令面板**：搜操作、搜声音、直接跳转。
- **设置**（侧栏底部齿轮）：引擎路径与模型、环境检测、自检、亮/暗主题、
  减少动效、释放显存。改动即自动保存。
- **亮暗主题**：侧栏底部太阳/月亮一键切换，跟随记忆。
